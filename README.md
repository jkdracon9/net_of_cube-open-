# 정육면체의 전개도

초등학교 5학년 수학 「정육면체의 전개도」 수업용 3D 탐구 프로그램입니다.

**바로 열기: https://jkdracon9.github.io/net_of_cube-open-/**

- **전개도 만들기**: 모서리를 눌러 고르고 가위로 자릅니다. 빛나는 면을 누르고, 면이 놓일 자리를 예측한 뒤 펼칩니다.
- **전개도 바꾸기**: 한 모서리에만 붙어 있는 면을 누르고, 그 면이 옮겨 갈 수 있는 자리를 찾습니다.
- 언어: 한국어 / English / Русский (오른쪽 위 지구본 버튼)
- 최신 Chrome, Edge, Safari(iOS 15.4 이상)에서 열립니다. 태블릿과 스마트폰에서는 터치로 조작합니다.

*Nets of a Cube — a 3D exploration tool for grade 5 mathematics (Korean / English / Russian).*
